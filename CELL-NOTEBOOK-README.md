# Cell Notebook

Open index.html and select Explore the Cell Notebook on the first project card. All pages work as static files, including the calculator and search. Keep the cells folder beside index.html when uploading to your portfolio host.

## Page plan
- cells/index.html: topic hub
- fundamentals.html: concepts and original format diagrams
- metrics.html: metrics and nominal calculator
- library.html: searchable manufacturer references and comparison
- p45b.html / p50b.html: source-linked cell records
- research.html: future personal evidence, with header-only CSV template

## Editing
Edit cell records and comparison in the HTML files; update values, source links and access dates together. Manufacturer records are separate from your own results. Add actual experimental evidence in research.html only when available. The library search reads data-name and data-capacity attributes on each record card.

No server, package installation, API key or build step is required. No external fonts, images or scripts are loaded. External reference links require internet.

## Before publishing
Replace portfolio contact placeholders. Check the manufacturer datasheet revision for any cell used in an engineering design. The two product records intentionally omit operating-current limits because those need full test-condition context.
