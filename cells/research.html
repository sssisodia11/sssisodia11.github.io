Project status: work in progress.

The portfolio identifies battery digital-twin and SOH/RUL projects. The workflow below is a proposed documentation structure, not a claim of completed experiments.

A research record that can be reviewed

  1. Identify the cell and question

    Record manufacturer, model, specimen ID and source revision. State what the model or experiment is intended to explain.

  2. Document the dataset

    Keep units, time base, equipment, ambient conditions and processing steps with the raw observations.

  3. Define the model

    Describe assumptions, parameter sources and the calibration subset. Distinguish fitted parameters from literature values.

  4. Evaluate separately

    Use held-out data, name the baseline, define the error metric and report where the model fails.
